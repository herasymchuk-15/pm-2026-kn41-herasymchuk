## 3. Definition of Done

Файл `dod.md`, умов у списку: 5. Скільки закритих історій його проходять, пораховано безпосередньо в розділі «Як це працює на практиці» файла `dod.md`.

Що з нього довелось прибрати, щоб він працював на проєкті одного виконавця: порівняно з ЛР2 (`lr02_approach/README.md`), де було заявлено обов'язкове парне code review, цю умову адаптовано під індивідуальний проєкт — замінено на самоперевірку за чеклистом наступного дня (або перехресне рев'ю з одногрупником) плюс автоматичний прогін валідатора/лінтера, бо формальна вимога другої пари очей на кожен коміт не виконувалася б.
