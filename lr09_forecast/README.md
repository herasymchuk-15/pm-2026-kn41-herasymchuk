## 2. Як рахувалася симуляція

| Поле                       | Значення                                                                                                                                                                                                              |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Інструмент                 | Скрипт Python (`random.Random(42)`)                                                                                                                                                                                   |
| Прогонів                   | 10 000                                                                                                                                                                                                                |
| Що тягнеться випадково     | Фактична velocity одного з двох завершених спринтів (`[7, 15]`)                                                                                                                                                       |
| Як рахується дата прогнозу | Останній день спринта, на якому закінчується робота: для сценарію «Весь перший реліз» `кінець першого спринта + (P − 1) × 14 днів`, для сценарію «Залишок після двох спринтів» `кінець другого спринта + P × 14 днів` |

```python
import math, random

def monte_carlo(velocities, remaining_points, simulations=10000, seed=42):
    rng = random.Random(seed)
    results = []
    for _ in range(simulations):
        rem, sprints = remaining_points, 0
        while rem > 0:
            rem -= rng.choice(velocities)
            sprints += 1
        results.append(sprints)
    results.sort()
    p50 = results[math.ceil(0.50 * simulations) - 1]
    p85 = results[math.ceil(0.85 * simulations) - 1]
    return p50, p85
```
